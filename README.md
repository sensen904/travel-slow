# 慢游 · 旅行规划

使用 HTML、CSS 和 JavaScript 实现的旅行规划网页体验版，无需安装依赖或执行构建。

[在线体验](https://sensen904.github.io/travel-slow/)

## GitHub Pages 部署

网站由 GitHub Pages 从 `main` 分支的根目录 `/ (root)` 自动部署。将网页文件提交到 `main` 后，GitHub 会自动更新在线版本；可在仓库的 Actions 或 Settings → Pages 查看部署状态。

## 功能

- 创建旅行、选择日期、填写同行人。
- 添加景点，编辑门票、游玩时间、开放预约及备注。
- 按早餐、午餐、晚餐、小吃整理美食清单。
- 上传拍照灵感和酒店截图，手动核对酒店信息。
- 出发前准备清单、行程排序、生成行程分享长图。

## 本地运行

在当前目录启动任意静态 HTTP 服务。例如，已安装 Python 时运行：

```sh
python -m http.server 8000
```

然后在浏览器打开 http://localhost:8000 。

## 文件

- `index.html`：网页入口。
- `app.js`、`app.css`：旅行规划界面与交互。
- `storage.js`：浏览器本地数据和图片存储。
- `web.js`、`web.css`：网页布局、响应式样式与分享入口。
- `assets/`：图标库和示例图片。

## 当前范围

行程使用 localStorage 保存，上传图片使用 IndexedDB 保存。数据仅保存在当前浏览器，不会跨设备同步；清除网站数据会删除这些记录。

酒店自动识别目前提供示例流程，真实截图需要手动核对。价格和交通时间为演示数据。外部地图支持按地点搜索，尚未实现完整路线自动编号。
